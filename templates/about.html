편집 원칙

{{ site.name }}는 신뢰를 가장 중요한 자산으로 여깁니다. 그래서 신문이 어떻게 만들어지는지 모두 공개합니다.

1. 사람이 쓴 보도와 공식 발표만 다룹니다

국내외 통신사·경제지·일간지와 중앙은행·감독기관의 공식 발표만 수집합니다. 보도자료 배포 사이트, 블로그, AI 요약 사이트는 출처에서 제외합니다.

2. 서로 다른 언론사 {{ cfg.edition.min_outlets }}곳 이상이 보도한 소식만 싣습니다

한 곳만 보도한 소식은 싣지 않습니다. 같은 회사의 계열 매체(예: 연합뉴스와 연합뉴스TV)는 한 곳으로 셉니다. 예외는 연준·한국은행·SEC 같은 공식기관의 1차 발표뿐입니다.

3. 기사를 지어내지 않습니다

{{ site.name }}는 새 문장을 쓰지 않습니다. 여러 언론사가 공통으로 보도한 소식을 묶어, 원 언론사의 제목과 기사 링크를 그대로 전합니다. 각 소식에는 보도한 언론사 목록이 함께 표시됩니다.

4. 중요한 순서대로 배치합니다

더 많은 언론사가 보도할수록, 통신사·공식기관 보도가 있을수록 앞에 배치합니다. 경제·투자·AI와 관련 없는 소식은 싣지 않습니다.

{% else %}

3. AI는 근거 자료 안에서만 씁니다

AI 기자는 해당 소식을 다룬 원문들만 받아 기사를 씁니다. 자료에 없는 수치·인용·전망은 쓰지 못하게 되어 있고, 투자 권유나 가격 예측을 하지 않습니다.

4. 게재 전에 문장마다 사실확인을 합니다

별도의 사실확인 단계가 제목·부제·요약·본문 문장을 원문과 하나하나 대조합니다. 근거가 없는 문장은 삭제하고, 제목이 근거 없거나 삭제 문장이 많으면 기사 자체를 싣지 않습니다.

{% endif %}

5. 숫자는 데이터 그대로 싣습니다

지수·환율·금리·원자재·암호화폐 시세와 투자자별 순매수는 데이터 제공처에서 직접 가져온 값입니다. 가져오지 못한 값은 추정하지 않고 비워 둡니다(—).

6. 출처를 모두 밝힙니다

모든 소식 아래에 원문 링크와 보도한 언론사 목록을 싣습니다. 기사의 저작권은 각 언론사에 있습니다.
